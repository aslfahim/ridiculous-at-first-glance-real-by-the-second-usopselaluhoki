One sentence, at most 200 characters, pitching a bizarre startup idea that
sounds absurd until you realise it would actually sell.

This entry pitches **professional excuse writers**: bulletproof sick-day and
deadline excuses, ghostwritten by ex-HR managers, for overworked employees —
because one airtight alibi can save a job, a promotion, and a whole weekend.

`main.py` (Python standard library only) writes that single sentence to
`/output/entry.txt`.
